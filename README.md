# Take-Home Test

This repository contains my submission for a take-home test. The app is an **Android application built in Kotlin**, using **XML layouts**, **RecyclerView**, and **MVVM architecture**.

## Features

- Display a list of names.
- Search/filter by name.
- Show an empty state when no results are found.
- Material 3 components: `MaterialCardView`, `TextInputLayout`, custom backgrounds.
- Secure mode enabled to prevent screenshots (`FLAG_SECURE`).

## Tech Stack

- **Language:** Kotlin
- **Architecture:** MVVM (ViewModel + LiveData)
- **UI:** XML layouts
- **Components:** RecyclerView, Material Components, TextInputLayout
- **Other:** LiveData, ListAdapter, DiffUtil
